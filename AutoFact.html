AutoFact

Informations du projet

  • Catégorie : Application
  • Date : 29/11/2022
  • Code source : github.com/4rn4ud/AutoFact

Détails techniques

Langage : C#
Technologie : Windows Forms / .NET
Outils : Visual Studio

Description :
AutoFact est une application permettant de gérer facilement sa facturation. Les utilisateurs peuvent :
• Ajouter leurs clients (nom, adresse, e-mail, téléphone…)
• Enregistrer des prestations ou produits avec leurs prix unitaires
• Générer devis, factures et avoirs
• Sauvegarder toutes les données en base locale
• Recalculer et régénérer les documents à tout moment

Une fenêtre récapitulative permet également :
• Le suivi mensuel et trimestriel pour l'URSSAF • L'affichage du chiffre d’affaires cumulé et net (après prélèvement URSSAF) • Le suivi du CA par client et par année

Développé en C# sous Windows Forms, utilisant une base de données locale (SQL).
