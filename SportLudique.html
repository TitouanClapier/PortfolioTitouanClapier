SportLudique

Créé par : Titouan CLAPIER & Arnaud LECHAT

Informations du projet

  • Catégorie : Application Web
  • Date : 17/11/2022
  • Code source : https://github.com/4rn4ud/SportLudique
  • Type : Projet d’étude

Détails techniques

Langages : PHP, HTML, CSS, JavaScript, SQL
Framework : Symfony
Librairie : Bootstrap
Outils : VS Code, VirtualBox, SQL Workbench, Teams, GitHub

Contexte :
Développement d’un site e-commerce dédié à la vente de produits sportifs. Le site permet de noter et rechercher des produits, de gérer les stocks, et d’attribuer différents rôles utilisateurs (administration, alertes, gestion des produits…).
