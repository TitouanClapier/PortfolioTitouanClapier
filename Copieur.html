Projet Copieur

Créé par : Titouan CLAPIER

Informations

  • Catégorie : Application Web
  • Date : 02/01/2023
  • Type : Projet de stage

Détails techniques

Langages : PHP, HTML, CSS, JavaScript, SQL.
Framework : Framework personnalisé.
Librairies : Bootstrap.
Outils : Visual Studio Code.


Contexte :
Développement d'une application de gestion d’un parc de copieurs subventionnés par le Conseil Général. L'application permet de gérer les copies réalisées sur différents sites, d'administrer les utilisateurs habilités et de modifier les informations des machines.
